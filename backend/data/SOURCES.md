## 확인된 사실

Task 3에서 `python -m pipeline.inspect` 실행 결과, 위 16개 파일 전부 `missing for ... : none`(config.COLUMNS의 별칭이 실제 헤더를 모두 커버함)이었다.

### 표준데이터 (전국도시철도역사정보표준데이터.xlsx)

- 헤더: 역번호, 역사명, 노선번호, 노선명, 영문역사명, 한자역사명, 환승역구분, 환승노선번호, 환승노선명, 역위도, 역경도, 운영기관명, 역사도로명주소, 역사전화번호, 데이터기준일자 (15개, 버전 2026-06-30)
- 총 1,099행. 수도권 밖 노선(부산 도시철도 1/2/3호선, 부산 경량도시철도 4호선, 부산김해경전철, 대구 도시철도 1/2/3호선, 대전 도시철도 1호선, 광주도시철도 1호선, 동해선, 대경선)은 `canonical_line`이 None을 돌려줘 걸러진다. 인천공항 자기부상철도(6행)도 노선명 "자기부상철도"로 마찬가지로 제외된다.
- 경전철 5개사(우이신설선, 신림선, 김포골드라인, 의정부경전철, 용인에버라인) 역은 표준데이터 노선명에 모두 들어 있다.
- GTX-A 역은 표준데이터에 없다. Task 13에서 `manual/extra_stations.csv`로 9개 역 좌표를 보충한다(대곡, 연신내, 서울역, 수서, 구성은 다른 노선 노드 좌표를 복사하고, 운정중앙, 킨텍스, 성남, 동탄은 카카오 지오코딩으로 보충).
- 1호선 코레일 구간은 표준데이터에서 노선명 경부선, 경원선, 경인선, 장항선으로 들어 있다. 5호선에는 하남선 구간이 포함되어 있다.

### 서울교통공사 두 파일

- 서울교통공사_역간거리_및_소요시간.csv 헤더: 연번, 호선, 역명, 소요시간, 역간거리(km), 호선별누계(km) (6개, 버전 2024-08-10)
- 서울교통공사_환승역거리_소요시간정보.csv 헤더: 연번, 호선, 환승역명, 환승노선, 환승거리, 환승소요시간 (6개, 버전 2026-08-31)
- 두 파일 모두 cp949 인코딩, 호선 컬럼은 숫자만("1") 형식이다. 소요시간과 환승소요시간은 mm:ss 형식(예: "02:00", "02:13")이다.
- Task 5 보정 결과: 1~8호선 실측 데이터로 도시철도 운행속도를 최소제곱 피팅 시 61.9 km/h (2026-09-28). config.SPEED_KMH를 60/75/110 (urban/regional/gtx)으로 설정했다. 차이 3.17%는 15% 이내로 수용 가능.

### 국가철도공단 노선별 역간거리 (13개 파일, 2026-09-28 확보)

- 모두 cp949 인코딩. 헤더는 두 가지 형태다.
  - 5컬럼: 철도운영기관명, 선명, 역명, 역간거리, 후행역간거리 (경강선, 경의중앙선, 경춘선, 공항철도, 수도권1호선, 수도권5호선, 수도권9호선, 수인분당선, 신분당선)
  - 4컬럼: 철도운영기관명, 선명, 역명, 역간거리(km) (에버라인, 인천2호선, 인천교통공사, 코레일)
- `선명` 값이 표준데이터나 서울교통공사 파일보다 축약된 표기로 들어 있어(예: "경의중앙", "수인분당", "경춘", "경강", "신분당", "공항", "1호선(경부선)", "1호선(경인선)", "1호선(서동탄선)", "1호선(광명선)") Task 3에서 `LINE_ALIASES`에 이 표기들을 추가했다. 반영 후 남은 미매칭 노선명은 "동해"(23행), "대경선"(8행)뿐이며 둘 다 수도권 밖 노선이라 의도한 대로 제외된다.
- 국가철도공단_코레일_역간거리.csv는 경부선/경인선/서동탄선/광명선(1호선), 수인분당선, 경의중앙선, 경춘선, 동해선, 4호선, 경강선, 3호선, 서해선, 대경선을 모두 포함하는 통합 파일이라 다른 노선별 파일과 데이터가 겹친다. Task 4 이후 파이프라인에서 중복 제거 방식을 정해야 한다.
- data.go.kr에 수인선(15041269)과 분당선(15041284) 데이터셋이 각각 등록되어 있었지만 내용이 완전히 동일한 수인분당선 63행(청량리~인천)이라, 중복을 피하려고 분당선(15041284) 쪽은 받지 않고 수인선(15041269) 파일 하나만 `국가철도공단_수인분당선_역간거리.csv`로 저장했다.
